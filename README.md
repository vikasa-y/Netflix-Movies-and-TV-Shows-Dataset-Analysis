# Netflix-Movies-and-TV-Shows-Dataset-Analysis

A beginner-friendly data analysis project using **Python, Pandas, and Matplotlib** to explore Netflix Movies and TV shows dataset.

### 🔧 Tools Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

### 📊 Analysis
* Cleaning Duplicate and Empty Values
* Number of Movies VS TV Shows
* Percentage of Ratings Contents
* No of Movie VS It's Duration
* Release Year VS Number of shows
* Top 10 Countries by Number of Showss
* Movies and TV Shows releases Over The Years

### 🎯 Goal

1. To practice working with a real-world dataset and extract meaningful insights using **Pandas and Matplotlib**.
2. This project helps to Make a Real-World dataset analysis Using **Pandas** 🐼 and **Matplotlib** 📈📊 libraries
